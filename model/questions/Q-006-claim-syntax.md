# What concrete Markdown syntax should represent Claims?

Inherited claim-level provenance is decided, but the file syntax remains experimental. We need to compare frontmatter Claim arrays, annotated Markdown sections, adjacent sidecar metadata, and other approaches without duplicating authoritative text or reducing readability for humans and coding agents.
