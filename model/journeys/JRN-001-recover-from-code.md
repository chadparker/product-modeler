# Recover and clarify a product from source code

1. The user supplies a small web-application repository.
2. The system inventories Product Evidence.
3. The AI constructs a provisional Product Frame and capability map.
4. The user explores entities and their evidence.
5. The AI asks the highest-impact Clarification Question.
6. The user answers through chat.
7. The AI proposes structured model mutations.
8. The accepted changes update both files and visual projections.
9. The user hands the Product Model directory to an external coding agent.
