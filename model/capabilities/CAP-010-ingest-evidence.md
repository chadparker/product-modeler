# Ingest product evidence

The user supplies prose specifications, source repositories, or both as evidence about a software product.

## Initial scope

- Prose and outline specifications
- Local web-application source repositories
- Optional runtime inspection when the application can be executed

Inputs are inventoried with enough identity and location information for later Claims to cite them.
