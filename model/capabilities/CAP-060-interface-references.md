# Preserve optional interface references

The user records how closely future implementations should preserve the Source Prototype's appearance.

Screens or individual regions can be classified as exact, structural, adaptive, inspirational, or unspecified. Evidence may include screenshots, render profiles, design tokens, assets, component states, and selected source references.

Appearance supplements behavioral intent rather than replacing it.
